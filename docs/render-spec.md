# 卡卡颂砖块渲染规范 v1（16×16 子格）

目标：所有砖块由**少量片元基元**在 16×16 子格上拼装而成，任意两砖相邻拼接时图案**完全耦合**（城接城无缝、路接路对齐、草对草），且绘制结果与引擎的边类型 / 连通段语义严格一致。

## 1. 网格与坐标

- 每块砖 = 16×16 单位格，坐标 (x, y)，x 向右、y 向下，取值 0…16（边界线）。
- 四边：N = y=0 行，S = y=16 行，W = x=0 列，E = x=16 列。
- 边中点：N(8,0)、E(16,8)、S(8,16)、W(0,8)。
- 旋转（顺时针 90°×r）：点变换 `(x,y) → (16−y, x)`，重复 r 次。与引擎 `rotated()` 的边旋方向一致（N→E→S→W）。

## 3. 耦合不变量（可程序校验）

> **I1 城市边**：凡边型为 C 的边，城填料必须覆盖该边全长（16/16），不得有任何缺口。
> **I2 道路边**：凡边型为 R 的边，路带必须以边中点为中心、垂直于边、宽度 4（即中点 ±2），且该边其余部分不得有路。
> **I3 场地边**：凡边型为 F 的边，不得出现路带；城填料仅允许按各片型定义的角区接触（城墙线收进砖内 ≥1u）。

推论：两砖相邻时，城-城边由 I1 全长贴合无缝；路-路边由 I2 中点对中点、宽对宽对接；草-草天然连续（草地是底色）。**墙线永不沿砖边绘制**（见 §6），因此相邻城砖之间不会出现隔断线。

## 4. 尺寸系统（整个体系互相锁死的根源）

- 城带深度 = **6**（单边城带 y∈[0,6]）。
- 路带宽 = **4**（中线 ±2）。
- 对边布局：城带 6 + 路带 4 + 城带 6 = **16**，恰好铺满 —— 「两独立城 + 东西直路」型（§8 T18）严丝合缝，无需任何特判。
- 岔路中心垫半径 = **2**（圆心 (8,8)，顶端 y=6 与城带底线相切不重叠）。

## 5. 片元基元库（12 种 → 拼出全部 22 种砖）

### 城基元（6）

| 基元 | 覆盖边 | 16×16 定义（正则朝向） |
|---|---|---|
| **C1** 单边带 | 1 条（N） | 填料矩形 (0,0)-(16,6)；墙线 y=6, x∈[0,16] |
| **C2** 角城（三角形） | 2 邻边（N+E） | 填料三角形 (0,0)(16,0)(16,16)；墙线 = 对角线 (0,0)-(16,16)（砖内对角，不沿砖边） |
| **C3** 对边贯通 | 2 对边（N+S） | 两条全宽带 y∈[0,6]、y∈[10,16] + 颈 x∈[6,10] y∈[6,10]；墙线沿颈两侧 x=6、x=10（y∈[6,10]）及带底 y=6、y=10（x∈[0,6]∪[10,16]） |
| **C4** 三边城 | 3 条（N+E+S，缺 W） | 全砖填充挖去 W 侧凹口 (0,6)-(4,12)；墙线沿凹口内缘 |
| **C5** 全城 | 4 条 | 全砖填充，无墙线 |

说明：两座独立小城（对边双 C1）= C1(N) + C1(S)（C1 旋转 180°），不单设基元。

### 路基元（4）

| 基元 | 形态 | 16×16 定义（正则朝向） |
|---|---|---|
| **R1** 直路 | 对边直穿（N+S） | 矩形 (6,0)-(10,16) |
| **R2** 弯路 | 邻边（N→E） | 折线路径 `(8,0)→(8,3)→Q(11,5)(13,8)→(16,8)`，线宽 4；弯道固定走此路径（最近点距 C2 对角墙 3.9u，路带缘仍 ≥1.9u），旋转后适配所有带城弯路砖 |
| **Rj1** 死路 | 1 臂（N） | 矩形 (6,0)-(10,8)，末端 (8,8) 圆头 r=2；若砖上有城凹口（C4），则止于墙基线（平头贴墙） |
| **Rj34** 岔路 | 3 或 4 臂 | 各臂矩形：N (6,0)-(10,8)、E (8,6)-(16,10)、S (6,8)-(10,16)、W (0,6)-(8,10)；中心垫圆 r=2 @(8,8)。2 臂邻边情形**不设此基元**，直接画 R2（两条独立路段共用一条弯道 drawing，拓扑与视觉均成立） |

### 附加基元（2）

| 基元 | 定义 |
|---|---|
| **M** 修道院 | 屋顶三角 (4,6)(12,6)(8,2) + 墙身矩形 (5,6)-(11,12)；仅出现在全草地砖 |
| **P** 纹章 | 旗杆 (12,1)-(12,6) + 旗三角 (12,1)(15,2.5)(12,4)；锚点随基元类别定（见目录），恒在城填料内 |

### 绘制顺序（每砖）

1. 草地底 → 2. 城填料 → 3. 墙线 → 4. 路（含弯/岔/垫）→ 5. 桥接层（仅 T17，见 §7）→ 6. 修道院 / 纹章。

装饰层（齿口雉堞、树、田纹）v1 不做；后续添加的唯一约束：**不得侵入任何耦合带**（城边全长、路带 ±2、R2 路径走廊）。

## 6. 关键规则：墙线只画内边界

城墙描线只出现在**城↔草的内部边界**（C1 底线、C2 斜线、C3 颈两侧、C4 凹口缘），严禁沿砖边描线 —— 否则相邻城砖接缝处会出现一道假墙。同理 R2/R1 路带两端不画端帽盖（对接处靠 I2 对齐）。

## 7. 桥接特例（T17 贯通城 + 东西直路）

路 y∈[6,10] 横穿全砖，城颈 x∈[6,10] y∈[6,10] 与路十字相交。绘制：先画路，再画城颈填料 + 墙线盖在路上方 —— 视觉为**城梁跨路桥**，拓扑与引擎 `[['N','S']]` 单一连通段一致。

## 9. 验收（程序化校验，实现时可挂进 test-game）

对每种砖型 × 4 个旋转：
1. 城边采样：沿边取 16 点，全部命中城填料（I1）。
2. 路边采样：偏移 6…10 命中路带，0…5 与 11…15 不得命中路（I2）。
3. 草边采样：16 点均不得命中路带；城接触区须落在本基元定义的角区范围内（I3）。
4. 路径走廊逐点距城填料 ≥1u（T17 桥接段除外——城梁有意跨路上方）。
5. 拼接冒烟：任意城边砖 + 任意城边砖对接后，接缝两侧城填料连续（无 1u 以下裂隙）。

## 10. 引擎对照备注

- 本规范与 `src/game.mjs` 的 TYPE_DEFS 一一对应；片元基元覆盖的边集合 == 该路段/城段的 `sides`，绘制连通性与计分连通性永不背离。
- 纹章砖在牌表中均为单城段，P 恒属唯一城段，无归属歧义。
